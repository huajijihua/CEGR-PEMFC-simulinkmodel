# Route A cEGR 交流会后路线裁决与研究问题

## 文档状态与适用范围

本文件根据 2026-08-12 阴极尾气循环技术交流整理，补充 Route A 当前指导；2026-08-14 按工程化架构总规划更新回流率和架构边界。它是**暂定研究裁决**，不是最终工程选型，也不改变 `platform_default` 与 `external_case` 的资产边界。

适用对象为 `RouteA_GasMixture_Derived` 下现有 Gas Mixture PEMFC 系统级模型、正式 runner 及其后续 S6 扩展。交流来源与不确定性见 `03_审计与研究/RouteA_cEGR_PEMFC_尾气循环技术交流会纪要_20260812_v01.md`。

## 裁决摘要

| 编号 | 暂定裁决 | 依据与边界 |
|---|---|---|
| D1 | cEGR 主研究窗口锁定为低负荷/怠速；默认采用条件启停，不设全负荷连续回流为目标。 | 低负荷加湿和降低最小运行电流是本次交流最明确的价值；中高负荷仅做独立探索。 |
| D2 | 现有压缩机前被动回流保持为当前模型的机理筛选路线，但其工程化声明被冻结。 | 饱和尾气冷凝与空压机耐湿尚无项目证据。下一扩展先过相态/露点与压差风险门槛。 |
| D3 | 主动、压缩机后回流建立为独立 `Active_cEGR` 配置/外部案例，不直接修改当前正式 `.slx`。 | 主动泵改变系统压力边界、寄生功耗和控制自由度；必须单列参数合同和验证。 |
| D4 | 方案比较至少包含：无回流、当前被动压缩机前回流、主动压缩机后回流、现有膜加湿器或协同方案。 | 比较必须在同一负荷、环境、边界和 KPI 定义下进行。 |
| D5 | 保留当前 I/P/V 运行边界和实际回流率闭环；未来将“需求电流/工况 -> 查表命令”作为主动回流策略对照。 | 工程查表与研究闭环解决的问题不同，不互相替代。 |
| D6 | 评价优先级为：低负荷湿度/冷凝/可靠性，随后是净功率与氢耗，最后才是耐久性外推。 | 堆电压变化不是单独的系统收益证据。 |
| D7 | cEGR 比例以分流点 `r_split = m_return/(m_return+m_exhaust)` 为主指标，同时报告空压机入口 `x_comp_in = m_return/(m_return+m_fresh)` 和 `r_fresh = m_return/m_fresh`；湿/干基及测量位置必须标注。旧 `r_mix` 保留为兼容名称，不再作为架构回流能力主指标。 | 文献中的比例定义非通用标准；分流点指标表达架构回流能力，入口混合指标表达空压机实际吸入组成，二者不能混用。 |

## 模型边界与接口合同

在引入任何新物理模块前，先冻结以下最小接口。

| 类别 | 信号/量 | 现阶段要求 |
|---|---|---|
| `u` | cEGR 目标比例、阀开度或主动泵命令 | 目标、执行器命令和实际流量必须可区分 |
| `w` | 环境温度、入口空气温湿、负载/电流需求、背压扰动 | 低负荷矩阵必须明确何者固定 |
| `y` | 阴极入口 RH、氧浓度、氧分压、氧过量系数、实际回流比例、压缩机/泵功率 | 控制策略和比较结论使用的观测量 |
| `z` | 混合点温压、蒸汽分压、露点裕度、支路流量、液水代理、相态诊断 | 调试与工程风险判断，不能省略为仅端电压 |

`p_O2 = y_O2 * p_abs` 的测量位置固定在阴极入口混合气。氧过量系数计算口径须在 runner 元数据中明确为新鲜供氧或堆入口总供氧，不能在同一结论中切换。

## 分阶段研究门槛

### G0：当前被动路线的低负荷可解释性

在扩展原 S6 被动 cEGR 矩阵前，先补充或验证：

1. 压缩机入口混合点的温度、绝对压力、相对湿度/蒸汽分压与露点裕度。
2. 汽水分离器后“无液水”与“低水蒸气分压”不是同义命题；需要液水代理或相态边界说明。
3. `r_split`、`x_comp_in`、`r_fresh`、目标比例和实际比例的统一口径。
4. 在固定新鲜风、固定总流量、固定氧过量系数三种边界中，至少选定一种作为每个矩阵的唯一约束。

**退出条件**：可说明当前被动支路的流向、氧稀释、加湿和冷凝风险是否同时可解释。未通过时，结果只能作为控制/网络计算例，不能作为压缩机前工程方案建议。

### G1：低负荷价值矩阵

在 G0 通过后，以低负荷为主构建配置对照。每个工况至少输出：

- 堆电流、堆电压、堆功率、压缩机/泵功率和净功率；
- 新鲜空气、回流气和混合气质量流量；
- 阴极入口 RH、`y_O2`、`p_O2`、氧过量系数；
- 混合点露点裕度、液水代理/排水状态；
- cEGR 目标值、执行器命令、分流点实际 `r_split`、空压机入口 `x_comp_in` 与 `r_fresh`。

**退出条件**：能够回答“在相同边界下，是否降低了低负荷可运行下限或改善了净收益”，而非仅报告端电压变化。

### G2：主动回流路线准入

主动压缩机后回流只有在具备以下参数合同后才进入模型实现：

| 参数 | 最低内容 |
|---|---|
| 泵/鼓风机能力 | 流量范围、压比或压升、效率/功耗曲线、转速/响应边界 |
| 热湿边界 | 入口与出口温度、温升、允许 RH、允许液滴/含液率、冷凝与结冰处理 |
| 压力边界 | 分离器出口、泵前后、空压机后、阴极入口绝压与压损 |
| 控制合同 | 查表/阈值/闭环的输入、输出、限制器与失效降级逻辑 |
| 验证证据 | 至少一项台架、供应商或作者原始数据；无数据时只能标识为假设扫描 |

**退出条件**：主动路线能用净功率、湿度、供氧与可靠性指标和被动路线比较；否则停留在参数敏感性层面。

### G3：耐久性与高负荷扩展

耐久性、冷启动和高负荷排水均是独立专题。进入前需有对应实验或高保真局部证据；不得以系统级稳态电压结果直接推出寿命结论。

## 与现有 S6 的关系

原 S6-S1 的 40 kW 被动 cEGR 稳态矩阵及其“系统网络随比例变化”的结论仍保留，但其适用范围仅限当前模型和设定边界。该结果不能回答：低负荷自增湿是否充分、压缩机前是否冷凝、主动泵功耗是否抵消收益、或耐久性是否改善。

下一次 S6 扩展应优先执行 G0，再决定是否将背压、低负荷或主动路线作为下一主矩阵；任何 `.slx` 结构修改前，需另行形成实现合同并经模型读回验证。
