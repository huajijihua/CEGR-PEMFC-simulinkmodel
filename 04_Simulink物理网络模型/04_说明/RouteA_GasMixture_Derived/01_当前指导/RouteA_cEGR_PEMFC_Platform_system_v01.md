# RouteA cEGR-PEMFC Platform System Specification v01

文件类型：平台系统规格  
日期：2026-07-24（初稿）；2026-07-27（更新：S2/S3 验证完成，补充当前状态）  
状态：已通过 S2/S3 验证，当前指导真源。S2 冷态 smoke 四个 case 全部通过，S3 恒电流/恒功率/恒电压 + cEGR 矩阵 + 入口组分控制全部完成。本规格的边界和接口已在当前模型中验证可行。

本文件包用于重新定义 Route A 的平台目标。它不是回退到官方案例重新建模，而是以官方案例、CEGR 文献和当前 RouteA 资产为三方输入，形成 RouteA_v2 的证据保留式重构边界。上一轮 Stage 1、v09、v10 或 I/P/V 迁移结果仍保留在实施记录和历史结果中，作为可追溯证据。

## 1. 平台目标

Route A 是一个面向系统尺度的阴极尾气循环 PEMFC 仿真平台，服务于：

1. 阴极尾气循环的流量、压力、组分、湿度、温度和水管理研究；
2. PEMFC 系统性能分析，包括电堆电压/功率、氧计量比、气路压降、cEGR 比和热状态；
3. 空气供应、背压、加湿、cEGR、阳极回流/吹扫和热管理策略开发；
4. 后续参数扫描、控制器比较、局部高保真模型结果回灌和外部案例复现。

平台的核心不是“支持尽可能多的命令字段”，而是保持一个物理闭合、参数可追溯、运行入口稳定的系统级 plant。任何新增设备或控制能力都必须能说明它解决了哪个研究问题、对应哪个物理状态、由什么证据验证。

## 2. 范围与非目标

### 2.1 当前范围

- 电堆/MEA、阳极气体域、阴极气体域和热端；
- 新鲜空气供给、阴极排气、阴极尾气到压缩机入口的 cEGR 支路；
- 阳极氢源、减压、阳极回流和吹扫；
- 加湿、背压和基础热管理接口；
- 电堆端电流、电压和功率测量；
- 稳态、瞬态和策略研究所需的统一输入与观测接口。

### 2.2 明确不在当前默认保真度内

- 产品级压缩机地图、效率、轴功率、喘振和机械惯量；
- DCDC、母线、电池、整车能量管理；
- 未经可验证证据支持的全液水库存、液水输运和分离效率模型；
- 把 10 kW 台架、DQ60 map、旧 CSV 或历史标定直接升格为默认参数；
- 为每种工况、负载或策略复制 `.slx` 和 runner。

这些内容可以作为后续扩展或 `external_case`，但不改变当前平台的默认边界。

## 3. 预期使用场景

| 场景 | 主要输入 | 主要输出 | 目的 |
|---|---|---|---|
| Nominal steady | 电堆电流、空气供给、背压、cEGR 目标 | I/V/P、lambda、压力、组分、RH、温度 | 建立系统性能基线 |
| cEGR sweep | cEGR 目标或阀命令、负载点 | 实际 cEGR、O2 稀释、功率、压力和水状态 | 研究循环比例影响 |
| Load transient | `I_cmd` 或用户侧 P/V 命令 | 动态电压、流量、压力、控制误差 | 研究动态响应和约束 |
| Control strategy | 控制器参数、设定点和扰动 | 追踪误差、限幅、稳定性和 KPI | 比较控制策略 |
| Parameter/scaling | 平台参数层和 `scaling_rule` | 性能随面积、单池数和额定等级变化 | 验证通用性 |
| External case replay | 显式案例包 | 与历史/台架数据的可比 KPI | 复现与边界审计 |

## 4. 系统边界与接口

模型采用电堆为中心的 plant 边界。脚本负责配置和调度，Simscape 物理网络负责气体、热和电堆动态；控制器只通过明确定义的信号接口作用于 plant。

### 4.1 `u`：主动控制输入

`u` 只包含模型可以主动施加的命令，不包含由物理网络响应得到的实际流量、压力或组分：

| 域 | 输入 | 单位 | 说明 |
|---|---|---:|---|
| Electrical | `I_cmd` | A | plant 的唯一内部负载接口；用户侧 Power/Voltage 命令必须先转换为它 |
| Cathode supply | `air_flow_cmd` 或 `air_oer_cmd` | kg/s 或 - | 同一 study 只选择一种空气供给语义 |
| Cathode pressure | `p_ca_out_cmd` | MPa abs | 背压设定点；不宣称为独立出口压力 |
| Cathode humidity | `RH_ca_cmd` | 0..1 | 加湿器设定点或旁路命令 |
| cEGR | `cegr_ratio_cmd` 或 `cegr_valve_cmd` | - 或 m2 | 默认只开放一种控制语义，另一种作为专门配置 |
| Anode supply | `p_h2_cmd`, `T_h2_cmd`, `y_h2_cmd` | MPa abs, degC, - | 氢源边界或减压器设定 |
| Anode operation | `recirc_cmd`, `purge_cmd` | - | 回流和吹扫控制接口 |
| Thermal | `T_stack_cmd` 或冷却侧设定点 | degC 或模型单位 | 只在已有热网络实际响应时开放 |

用户侧可以提供 `Current`、`Power` 或 `Voltage` 研究命令，但模型内部只保留一个 `I_cmd` plant 端口。`Power` 通过 `I_cmd=P/V` 转换；`Voltage` 由一个明确的电压控制器输出 `I_cmd`。三者不是三个不同物理 plant。当前活动 panel/runner 统一从 cold start 进入，不加载 operating point。

### 4.2 `w`：外部扰动和边界条件

`w` 包括环境压力/温度、入口组成、冷却环境、外部背压、初始负载扰动和未由控制器闭环的边界条件。`w` 不应通过命名为 `cmd` 的变量写入控制器或被结果审计误认为主动执行器。

### 4.3 `y`：控制器可见的测量量

`y` 只发布模型中实际存在传感器和转换器的量：电堆电流、电压、功率、温度，阴极/阳极入口和出口压力、温度、质量流量、组分、RH，cEGR 实际流量/比例，阀命令和限幅状态，吹扫状态以及水分离输出。

### 4.4 `z`：真值和审计量

`z` 用于结果审计，不作为默认控制反馈，包括各物种质量流、库存变化、混合点前后组分、阀压差、热流、反应量、守恒残差和内部状态。没有对应日志或传感器的量不能写入 `y` 或报告为已验证 KPI。

## 5. 保真度等级

| 等级 | 用途 | 必须具备 | 当前定位 |
|---|---|---|---|
| L1 | 拓扑和接口 smoke | 官方块、端口闭合、最小求解 | 重置后的第一道门 |
| L2 | 系统尺度研究 | 四物种气体域、MEA、BOP 动态、cEGR 物理路径、热端和观测 | Route A 默认目标 |
| L3 | 局部机理/产品校核 | 可验证的设备地图、液水、局部空间分布或实验标定 | 后续扩展，不阻塞 L2 |

Route A 不因未来需要 L3 就在当前 L2 模型中提前加入无法验证的设备细节。每个 BOP 模块必须标记为官方复用、L2 等效、待标定或未开放。

## 6. 平台验收目标

平台可以被称为“可用的通用系统模型”必须同时满足：

1. 只有一个当前系统 `.slx`，且其顶层自然容器与电堆、阴极、阳极、热、电负载、控制和观测职责一一对应；
2. 所有活动物理端口闭合，模型更新/编译通过，结构检查中的剩余 warning 已有分类和责任边界；
3. `platform_default` 参数可独立初始化，冷态 nominal smoke 通过；
4. 研究命令不会改变物理拓扑，I/P/V 只改变负载命令或控制器行为；
5. cEGR 的目标值、实际值、分母定义、方向和零循环语义明确，物种和质量流闭合可审计；
6. 稳态、瞬态、失败分类和结果保存拥有同一个轻量 runner 契约；
7. 至少完成一个低负载、一个额定附近和一个高负载代表性 case 的 agent 端到端验证后，才允许交接大规模矩阵。
