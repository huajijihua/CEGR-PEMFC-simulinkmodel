# P5 仿真平台前端输入能力

## 目的

面板是 Route A 的统一仿真操作入口：仿真人员在基础、高级和系统设备参数设置页输入工况与设备参数，点击运行后由同一 `SimulationInput -> sim -> SimulationOutput` 链路完成计算；系统模型参数页用于查看完整模型参数和其物理归属。面板不得越过 Route A 被动 cEGR、cold-start-only 与 L2 水管理的当前模型边界，但模型已实际引用且适合研究人员设置的参数应逐项补齐为可控输入。

## 五页签职责

| 页签 | 职责 | 输入状态 |
|---|---|---|
| 基础 | 常用电边界、空气控制、背压/加湿、cEGR、热边界与时长 | 可编辑 |
| 高级 | 时序命令、控制器、源边界、组分、数值设置与阳极输入 | 可编辑 |
| 系统设备参数设置 | 电堆/BOP 标量参数、设备特性曲线和已完成写入适配的设备参数 | 当前 54 项可编辑；派生/结构/组编辑项按规则处理 |
| 系统模型参数 | 模型工作区全量目录、实际块引用、面板承接状态、当前草稿与最近一次运行快照 | 只读 |
| 帮助 | 操作流程、输入约束、模型边界与结果判读 | 只读 |

## 参数开放规则

1. **模型已引用、尚未开放的参数必须逐项审查并优先补齐。** 参数注册表、`Simulink.findVars`、唯一写入目标、单位/范围/校验器、编译要求和代表性响应证据闭合后，转入基础页、高级页或系统设备参数设置页；只有明确属于内部建模或初始化的变量才继续只读。
2. **本轮 B1 已将 10 项 BOP 标量接入设备页。** 设备页当前为 `129 = 54 可编辑 + 74 platform_default 源目录 + 1 未接入审查`。74 个源目录叶项是默认参数树的可追溯目录，不是额外的活动输入；本轮新增的默认叶项因此使目录总行数高于原计划的 121，但不改变活动输入计数。
3. **当前模型未引用的设备参数不直接开放。** 先核对它是否被活动模型或面板计算链使用；无用途的历史遗留项移出默认参数链并归档；确有研究用途的项先完成模型接入，再重新审计。
4. **派生量、结构量和编辑器组成员保留可见性，但不提供独立数值框。** 例如由 cEGR 管径派生面积、由散热器几何派生换热面积，以及空压机三个图谱数组的成组编辑。操作者编辑规范输入或图谱编辑器，面板负责推导、校验和原子提交。
5. **52 个未引用/辅助工作区变量必须进行用途清理。** 查表、物性、配置元数据等确属内部支撑的保留为只读；旧别名、profile shadow 和未接入的历史变量移除或归档；有明确物理用途的变量补齐模型接线后再决定是否开放。
6. **21 个模型已引用但待开放变量已按 B1-B3 收口。** B1 开放 10 项 BOP 标量；B2 开放 6 项环境/空气 PID/直接 cEGR 研究参数；B3 保留 5 项内部几何、拓扑和数值保护变量只读。因此当前 `86 = 81 面板已承接 + 5 只读内部/结构变量`。此前 24 项候选中的 `drive_cycle_time`、`tank_yH2` 和 `radiator_tube_Leq` 已由现有 profile/设备几何派生链覆盖，不再作为独立输入缺口。
7. 阴极/阳极分离器的“流通面积”和“层流分数”对应当前实际 `Flow Resistance (FC)` 块，不得误称为分离罐直径或分离效率。cEGR PI 的 Kp/Ki 是控制器参数，保持在高级页，不归为设备固有性能。

### B1-B3 当前处置

- B1 设备页已开放：`anode_separator_dp_nominal`、`anode_separator_mdot_nominal`、`intercooler_area`、`intercooler_laminar_fraction`、`cegr_cond_tau`、`cegr_inlet_mixer_p0`、`cegr_outlet_chamber_p0`、`cegr_pipe_extra_length`、`cegr_pipe_p0`、`cegr_valve_open_min_area`。每项均有 registry、单位/范围、`simCase.controls.devices` 字段和 `SimulationInput` 写入目标。
- B2 高级页已开放：`env_T`、`env_p`、`routeA_air_pid_Kp`、`routeA_air_pid_Ki`、`routeA_egr_valve_area_direct`、`routeA_target_egr_ratio_comp_in`。环境边界与供气源边界分开；直接 cEGR 字段仅在直接控制模式启用，目标比例模式仍以 `cegr.targetRatio` 为主入口。
- B3 只读保留：`anode_tube_D`、`cathode_tube_D`（共享内部几何）、`cegr_comp_map_t_denom_epsilon`（图谱数值保护）、`stack_num_channels`、`stack_w_channels`（通道结构/拓扑）。模型参数页显示其物理含义、引用块、默认值、只读原因和开放条件。

当前契约和 B1 设备扰动 cold-start smoke 已通过；B2 的环境/PID 与直接 cEGR 组合在正式模型初始条件求解阶段仍触发 `NE_DAE_IC_Failure`，因此已完成“写入链可用性”但尚未完成该组合的物理响应验证。后续不得把该 smoke 失败误写成参数映射失败，应先处理模型初始化条件或补充可收敛的验证工况。

## 模型-面板参数审计

`routeA_audit_parameter_inventory` 是模型与面板之间的参数事实入口。它从当前 `.slx` 的模型工作区和 `Simulink.findVars` 生成 [模型-面板参数汇总表](RouteA_cEGR_PEMFC_模型-面板参数汇总表_v01.md)，并检查三类覆盖：

1. 所有活动面板参数的实际写入目标是否被模型引用；时序电流/功率边界属于 FuelCell 库封装输入，必须另有实际仿真响应证据。
2. 所有模型工作区变量是否在“系统模型参数”页显示其物理角色、引用状态、代表模块和面板承接状态。
3. 模型真实参数但尚未开放时必须标为目录只读，并进入“参数开放/保留只读/移除归档”三选一的处置清单；工作区闲置变量或未接入变量不得直接变成 UI 输入。
4. 同一物理几何量不得由多个独立面板数值框竞争写入。当前 `device.cegr.pipeDiameter_m` 是唯一管路几何输入，`cegr_pipe_area` 在 `SimulationInput` 中按 `pi*D^2/4` 同步推导。

## 输入与运行契约

面板以 `draftSimCase` 保存五页签共用的草稿，运行时统一走：

`UI -> draftSimCase -> routeA_validate_case -> SimulationInput -> model -> SimulationOutput`

设备默认恢复重置设备页的标量和空压机图谱默认值，不改变研究工况。高级时序命令格式为 `t,value; t,value`；时间必须非负且严格递增，留空时使用标量命令。

设备输入以可解释的标量数值框、成组几何输入和特性曲线编辑器呈现，面向模拟不同真实设备。每次改变参数后重新运行一个工况即可形成对照研究。所有设备值仍由 `platform_default` 提供默认值，并通过 `SimulationInput` 或明确的 profile/派生写入目标覆盖模型输入。

空压机图谱采用独立、可调整大小的表格编辑器，而非普通数值框。编辑器提供转速断点表、压比断点表、修正质量流量矩阵、同步增删行列和图谱预览。只有三个数组同时满足有限数、转速非负且严格递增、压比不小于 1 且严格递增、流量非负、矩阵尺寸等于 `numel(p_ratio_TLU) x numel(rpm_TLU)` 时，才写回 `draftSimCase` 并在运行前通过 `SimulationInput` 同时覆盖 `comp_rpm_TLU`、`comp_p_ratio_TLU` 和 `comp_mdot_corr_TLU`。

## 布局与交互

1. 五个配置页直接由可滚动配置容器承载；切换页签时自动定位到当前页面顶部。
2. 当前页签及当前曲线类型使用高对比蓝色选中态。
3. 配置区与结果区之间的分隔条可拖动，面板按照当前宽度比例重排；不改变模型、输入草稿或结果。

## 非目标

本能力不以 UI 控件掩盖模型缺口，不把未接入 BOP 的历史变量伪装成可调设备，不新增主动循环泵或型号库，也不扩大液水结论能力。模型参数清理、接口补齐和面板开放必须保持同一审计链和可回归验证入口。
