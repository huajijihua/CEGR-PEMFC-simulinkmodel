# Route A cEGR-PEMFC 两种阀门被动架构与聚焦模型改造实施方案

文件类型：当前指导、模型结构改造方案和验收门
日期：2026-08-17
状态：P0.5、P1、P2 和 P4-A 已完成；原 P3/P4 在单一模型中的试验结果保留为历史证据。2026-08-14 经模型读回与用户复核，原单一模型把自增湿路径与仅有湿侧的 L2 流阻串在一起，不能形成有效的 A/B 对照。现有两个独立聚焦模型的裁决不变：A 为无外部加湿器的自增湿电堆，B 为含真实干湿两侧水热交换的膜加湿电堆。模型 A 的外部 240 kW 无 CEGR 压力链和低负荷 CEGR 行为筛选已完成；受限于允许拟合参数，240 kW 极化绝对误差门未通过，不能称为完成性能标定。模型 B 仍待膜组件参数合同，P5 性能研究继续暂停。

## 1. 目的和范围

本方案只解决两个问题：

1. 判定用户两张结构图表达的气路是否正确，并给出必须补画或改画的部分；
2. 将两张图映射为当前 Route A 聚焦模型的可实施改造任务。

本阶段不进行 cEGR 最优比例、性能排序、设备参数标定、PID 整定或辅机功耗结论。只有模型结构通过本方案的 Gate 0--Gate 4 后，才进入 cEGR 性能和设备控制研究。

本次架构裁决允许两套独立 `.slx`，因为两种湿化方式的气体端口、质量传递和热传递拓扑不同，不能再通过同一条物理链和元数据标签表达。仍只保留一个正式研究 runner：它在每次 study 开始时锁定一个模型标识，复用同一 case、参数、观测和结果契约；不得在同一次 study 中混合两个模型的结果。

本次计划更新将模型限定为气相 L2 筛选模型：在质量流量、绝对压力、温度和湿气组分一致的前提下，识别饱和、露点和潜在冷凝风险；不引入液水库存、液滴输运、排液动力学、分离效率或压缩机进液损伤模型。

## 2. 结构图识别结论

### 2.1 图示中正确的部分

两张图共同表达的主气路方向是正确的：

```text
外界空气
 -> 空压机前混合室
 -> 空压机
 -> 中冷器
 -> 阴极入口
 -> 电堆阴极
 -> 阴极出口
 -> 尾气处理
 -> 回流至空压机前混合室或外界排放
```

两张图都采用空压机入口回流，且没有独立循环泵或回流风机，按项目定义属于被动压力差式 cEGR。空压机、背压、CEGR 阀和电负载可以属于控制层，但阀门是否受控不改变“被动式”的能量拓扑分类。

### 2.2 必须改画的部分

#### 2.2.1 CEGR 阀后必须画成两个明确分支

当前简图的“水汽分离器 -> CEGR 阀 -> 外界排放出口”容易被读成排放气体也必须经过 CEGR 阀。正式图应明确画出一个分流节点：

```text
水汽分离边界
 -> 分流节点
      -> 回流支路 -> CEGR 阀 -> 回流管路 -> 空压机前混合室
      -> 排放支路 -> 外界排放出口
```

如果实际硬件是三通阀，图中应画三通阀并标明回流口、排放口和入口；如果实际硬件是二通 CEGR 阀加独立排放通道，图中应画两个物理支路，不能用一条串联线代替分流。

因此，`r_split` 必须在分离边界后的分流节点定义：

```text
r_split = m_return / (m_return + m_exhaust)
```

#### 2.2.2 背压阀要明确是公共主干压力边界还是排放支路阀

用户图意图是：

```text
阴极出口 -> 背压控制 -> 水汽分离 -> 回流/排放分流
```

这是可以作为目标架构的，但图中应在背压阀旁标注“公共出口压力控制”，并画出其下游压力边界或排放出口。压力释放阀通常需要排向环境或低压容腔，不能只画成没有下游边界的串联元件。

当前模型的 `Pressure Relief Valve` 在排放支路，不等价于公共主干背压阀。因此不能通过改名完成改造，必须先检查官方阀的 conserving-port 语义、流向和压力设定方式，再选择公共背压实现。

#### 2.2.3 水汽分离器要标明液水出口或“气相边界”状态

如果当前阶段没有液水库存、分离效率和排液参数，图中不要把它画成已经闭合的真实分离器。建议标注为：

```text
水汽分离边界（L2，分离效率/液水出口待定）
```

如果后续加入真实设备，至少要有气体入口、气体出口、液水出口和压降；若排液有阀门或液位控制，再增加排液控制接口。

#### 2.2.4 配置 B 的湿侧和干侧方向正确，但要画清流体端口

配置 B 的目标顺序是：

```text
压缩空气/回流混合气 -> 膜加湿器干侧 -> 电堆阴极入口
阴极尾气 -> 背压边界 -> 膜加湿器湿侧 -> 水汽分离边界
```

膜加湿器应画成两条相互独立的气体通道，中间用膜换湿/换热表示；不能画成单个串联气路上的“加湿器”方框。

### 2.3 建模前 L2 气相热湿-压力契约

两种配置在建立或移动任何物理块前，必须先冻结以下共同契约：

| 类别 | 共同要求 | 结论边界 |
|---|---|---|
| 质量与组分 | 每个关键节点记录总质量流量和四物种气相组分；回流、排放和新鲜空气均采用明确测点、正方向和 kg/s 单位 | 只在声明的气相边界内检查质量闭合；反应生成水或已声明的边界源项必须单列，不能隐含在误差中 |
| 压力 | 节点使用绝对压力；阀、管路、流阻、膜加湿器两侧和公共背压均记录压差及实际流向 | 被动回流只能由节点压力、阀面积和支路阻力产生，不得用独立质量流量源或泵制造回流 |
| 温度与焓 | 节点记录气体温度；混合、压缩、固定温度边界和已建热端口决定气相温度状态 | 第一轮不闭合中冷器冷却侧、再热器或完整热管理；固定堆温不等于热管理控制 |
| 湿度与潜在冷凝 | 计算 `p_H2O = y_H2O * p_abs`、`S = p_H2O / p_sat(T)`、露点和露点裕度 | `S > 1` 或负露点裕度只报告潜在冷凝风险/气相超饱和代理，不能报告液水库存、液滴量、排液能力或分离效率 |
| 气相分离边界 | 第一版仅为气相路径、压损和风险观察位置 | 未建立液水质量守恒与液水出口前，分离边界不得改变气相水蒸气组分或作为真实水分离器宣称 |

最低观测节点为：空压机前混合点、压缩机出口、中冷器后、阴极入口、阴极出口容腔、公共背压前后、分离边界前后、回流/排放分流后；配置 B 额外记录膜加湿器干侧和湿侧的入口/出口。每个节点的 `p_abs`、`T`、`y_i` 和相关 `m_dot` 必须在 case 和结果中具有唯一名称、单位与物理位置。

## 4. 目标模型架构

### 4.1 共享结构

两种配置共享以下结构：

```text
Air Intake
 -> CompressorInletMixer
 -> Compressor / Compressor Volume
 -> Intercooler boundary
 -> Humidification configuration
 -> Stack cathode
 -> CathodeOutletChamber
 -> Common backpressure boundary
 -> Gas-phase separation boundary
 -> Return/exhaust split
      -> CEGR valve -> EGR Pipe -> CompressorInletMixer
      -> Exhaust outlet boundary
```

目标架构标识：

```text
Passive_SelfHumidifying_PostSeparatorGas_CompressorInlet
Passive_ExternalMembraneHumidifier_PostSeparatorGas_CompressorInlet
```

**架构拆分裁决（2026-08-14，优先于本节的“共享结构”表述）：** 共享的是 case、参数、观测和结果契约，不再是同一条 Simscape 气路。模型 A 的正式气路不含 `Cathode Humidifier`、单侧 `MIn` 注水或 `MembraneHumidifierWet_L2_FC`；模型 B 的正式气路必须有“中冷器后 -> 膜干侧 -> 阴极入口”和“公共背压 -> 膜湿侧 -> 气相分离边界 -> 分流”两条独立气路，以及跨膜水蒸气和热传递。两个模型的正式文件名分别为 `PEMFuelCellSystem_Cathode_cEGR_SelfHumidifying_v01.slx` 和 `PEMFuelCellSystem_Cathode_cEGR_ExternalMembraneHumidifier_v01.slx`。

### 4.2 配置 A：自增湿电堆

配置 A 不设外部加湿器，而不仅是把水质量注入命令设为零：

```text
Intercooler boundary -> humidifier bypass -> Stack cathode
```

必须保留并核对：

- MEA 反应产水；
- 阴极出口水蒸气和冷凝状态；
- 分离后回流水蒸气；
- 压缩机入口混合点水蒸气；
- 电堆阴极入口 RH、露点和冷凝风险；
- 气相水量闭合。

配置 A 不新增名为“自增湿器”的设备块。自增湿是系统水管理结果，不是单独执行器。

### 4.3 配置 B：外部膜加湿电堆

配置 B 使用独立的两侧膜加湿器模型：

```text
压缩机/中冷器后 -> membrane humidifier dry side -> Stack cathode
Stack exhaust -> Common backpressure -> membrane humidifier wet side
                         -> separation boundary -> split
```

膜加湿器至少需要：

- 干侧气体入口/出口；
- 湿侧气体入口/出口；
- 两侧压力、温度、质量流量和组分观测；
- 跨膜水传递；
- 必要的跨膜热传递；
- 两侧压降和气体库存/管路语义。

当前 `FuelCell_lib` 读回中没有可直接复用的双侧膜加湿器块。模型 B 必须先完成受控 Simscape 两侧组件的输入输出和参数合同，之后才允许接入；禁止用 MATLAB Function 代替膜传质、传热或气体质量守恒。组件至少应有干湿两侧气体入口/出口、两侧压降、跨膜水蒸气通量和跨膜热通量；相关参数未取得来源前只能建立接口，不能运行性能对比。

## 5. 具体改动清单

### 5.1 `Cathode_Exhaust_Backpressure_Water`

这是本次最优先的结构改动区域：

1. 保留 `CathodeOutletChamber` 作为阴极出口库存节点；
2. 在分流前建立公共背压边界，明确压力设定和排放边界；
3. 在公共背压之后建立气相分离边界，第一版可为官方 `Flow Resistance (FC)` 加明确的 L2 分离状态；
4. 分离边界之后建立显式回流支路和排放支路；
5. 回流支路依次连接质量流量传感器、CEGR `Local Restriction (FC)` 和 `Pipe (FC)`；
6. 排放支路连接质量流量传感器、必要的出口限制和环境 `Reservoir (FC)`；
7. 将 `r_split` 的两个质量流量观测点固定在分离边界之后；
8. `SeparatorOrCondensation` 不再作为气体分离或组分修改模块。

如果官方压力释放阀无法表达公共主干压力控制，则保留其作为排放边界，并另行使用同一 `FuelCell` 域中端口语义明确的压力/阻力结构；不得把排放支路阀误报为公共背压阀。

### 5.2 `Cathode_Air_cEGR_BOP`

1. 保留 `CompressorInletMixer`、压缩机图谱/容积、中冷器 L2 接口、EGR 阀和 EGR 管；
2. 配置 A 在 `Intercooler_L2_Interface` 与阴极入口之间启用官方加湿器旁路，禁止当前 `MIn` 水质量注入；
3. 配置 B 在同一位置接入双侧膜加湿器干侧；
4. 不改变回流接入位置，回流仍返回 `CompressorInletMixer`；
5. 保留空压机目标 OER/质量流量/直接命令三种模式，但暂不把压缩机功率当作已闭合的设备指标。

### 5.3 `Stack_Core`

第一阶段不修改 MEA 主物理结构，只做以下读回和观测准备：

1. 确认 MEA 水生成和跨膜水传输的实际参数、单位和写入点；
2. 确认阴极气道水蒸气质量分数、RH、温度和冷凝输出；
3. 若官方 MEA 没有直接输出膜含水量，则登记为观测缺口，不在 MATLAB Function 中假造膜含水量；
4. 固定 `80 degC` 仅作为第一轮结构 smoke 边界，不作为热管理控制模型。

### 5.4 `System_Control_Observability`

共同控制接口：

| 接口 | 当前状态 | 改造要求 |
|---|---|---|
| 电负载 | 已有 I/P/V | 保留 |
| 空压机 | 已有 OER/质量流量/直接命令 | 保留，增加配置状态记录 |
| 公共背压 | 当前是排放支路语义 | 增加公共出口压力目标和实际压力观测 |
| CEGR 阀 | 已有 PI/直接面积/执行器 | 保留，反馈改用分离后回流率 |
| `r_split` | 当前为出口分支代理 | 改为分离后回流/排放支路定义 |
| 加湿器 | 当前为 RH/水注入接口 | A 标记旁路，B 改为膜加湿器参数/旁路接口 |

### 5.5 runner 和结果契约

不创建第二个 runner。正式 runner 增加或使用以下配置字段：

```text
architecture.humidificationMode
architecture.backpressureLocation
architecture.separatorStatus
architecture.splitLocation
controls.cegr.returnValveArea
controls.backpressure.targetPressure
```

配置 A 和 B 必须共享同一套 `r_split`、`x_comp_in`、`r_fresh`、压力链、湿度链和冷凝风险输出。结果中必须记录 `implemented`、`structurally_verified`、`executed`、`behavior_verified` 和 `not_validated` 状态，不能用架构名称替代证据状态。

## 6. 模块和实现约束

优先复用当前已读回的官方 `FuelCell_lib` 模块：

- `Constant Volume Chamber (FC)`：混合室、出口容腔和必要的缓冲容腔；
- `Flow Resistance (FC)`：中冷器、等效分离压损和未标定设备边界；
- `Local Restriction (FC)`：CEGR 阀和有压差驱动的限制元件；
- `Pipe (FC)`：回流管路、湿侧/干侧气体管路和库存；
- `Mass Flow Rate Sensor (FC)`：回流和排放支路；
- `Composition and Humidity Sensor (FC)`：分离边界、混合点、膜加湿器两侧和电堆入口；
- 官方压力/温度传感器和 `Reservoir (FC)`：压力链和排放边界。

以下内容不能在本方案中直接当作已具备能力：

- 真实液水分离效率；
- 液水库存、液滴携带和排液；
- 膜加湿器跨膜传质和传热；
- 完整中冷器换热控制；
- 压缩机效率、功率和喘振边界；
- 真实电堆分布式流阻。

## 7. 分阶段实施和出口门

### P0：结构图冻结

产物：修正版两配置结构图、接口表、L2 气相热湿-压力测点表和待确认决策表。

最低要求：显式画出分离后回流/排放两支路，明确公共背压位置，配置 B 画出干侧/湿侧，所有控制对象和被动设备分开标识；逐节点固定 `p_abs`、`T`、`y_i`、`m_dot` 的单位、方向和采样位置；分离边界明确为不改变气相组分的 L2 边界。

**温度边界说明（2026-08-14）：** 模型 A 的电堆采用 `focused_stack_temperature_C=80 degC` 固定热边界；阴极新鲜气/环境由 `env_T=20 degC` 写入；阳极边界由 `focused_anode_boundary_T_C=20 degC` 写入。回流支路没有独立温度设定，回流气温度由阴极出口、管路和入口混合计算。当前聚焦模型不含冷却回路、散热器或可验证的中冷器热管理，因此空压机后、阴极通道和出口温度是气相网络计算量，不能解释为受控设备温度或热管理性能。默认阀面积上限 case 的混合点/压缩机后/阴极出口温度分别为 44.47/79.98/79.98 degC，混合点露点裕度为 6.29 degC。

**外部 240 kW 电堆与 BOP 筛选迁移（2026-08-14）：** 模型 A 当前正式文件已按外部案例迁移为 606 片、每片 380 cm²（总有效面积 230280 cm²），`stack_iL=2.5 A/cm²` 仅作为高于实测 1.9 A/cm² 的筛选上限，不是验证后的最大电流密度。为保持几何相似的阴极流通面积，`stack_w_channels=sqrt(380/280)`；额定阴极流量/压降取外部案例高负荷值 `0.27182 kg/s`、`36.8422 kPa`，并将中冷器、分离边界、回流管和 CEGR 阀的通流尺度、压缩机筛选图谱同步放大。`Stack_Core/CathodeOutletResistance` 的 `laminar_fraction=0.1` 用于补充低流量线性损失，未把外部“干出/湿入”压差直接宣称为电堆通道标定。正式 case 适配器已把这些外部案例参数写入 `SimulationInput`，避免模型工作区值被旧的通用参数链覆盖；空压机控制最小电流改为 `3.8 A`，使 0.1 A/cm² 及以下筛选不被 95 A 的遗留下限钳制。该参数层始终标记为 `external_case`，不进入 `platform_default`。

在 `cEGR=0`、600 s 冷态、尾窗 540--600 s 的正式 runner 运行中，且 `study.model` 核对为 `PEMFuelCellSystem_Cathode_cEGR_SelfHumidifying_v01`，38 A（0.100 A/cm²）得到新鲜空气质量流量 `0.036215 kg/s`、压缩机转速 `6692 rpm`；721 A（1.897 A/cm²）得到 `0.271814 kg/s`、`56960 rpm`。高负荷时压缩机出口/中冷器后/阴极出口容腔绝压分别为 `0.252949/0.250729/0.212562 MPa(abs)`，阴极压降 `0.038167 MPa`；低负荷相应为 `0.119566/0.119527/0.118755 MPa(abs)`，压降 `0.000772 MPa`。两个 case 均通过现有严格稳态、气相闭合、氧过量、压力方向、面积和压缩机转速/流量跟踪门。高负荷模型电堆功率 `323.20 kW`，高于外部表中 721 A 的 `279.33 kW`；低负荷模型 `25.12 kW`，高于外部表中 38 A 的 `19.03 kW`。因此本迁移已经验证几何、流量和压力链的系统筛选可运行性，尚未完成电化学极化标定。外部表压力测点的物理位置也尚待确认，尤其低负荷表中约 10 kPa 压差不能直接等同于当前模型阴极通道压降。

**无 CEGR 引射器边界支持（2026-08-14）：** 已基于上述两个 `cEGR=0` 正式 case 输出空压机入口、出口、中冷器后/入堆和堆出口四个气相边界，供“压缩机后引射”方案进行前置数值筛选。压缩机出口和入堆前的气相摩尔组分均约为 `[N2,O2,H2,H2O]=[0.7785,0.2100,0,0.0115]`，堆出口组分随电化学耗氧和产水变化，完整表格见 [无 CEGR 引射器边界数据](../../../../03_结果/RouteA_Cathode_cEGR_Focused/RouteA_Focused_NoCEGR_EjectorBoundary_20260814.md)。无 CEGR 时不建立回流边界，也不提供“新鲜空气+回流”的混合数据。压缩机在本模型中仍是质量流量源配合筛选转速图谱，中冷器仅有气相流阻而无冷却回路；因而可将质量流量、气相组分和压力作为系统级引射器筛选输入，温度只可作为当前模型内部状态样本，不能用于压缩机效率、引射器热设计或硬件出口温度结论。

**外部 240 kW 自增湿半定量标定更新（2026-08-17，覆盖本节早期 240 kW 性能数值）：** 目标固定为 `PEMFuelCellSystem_Cathode_cEGR_SelfHumidifying_v01`，并始终标记为 `external_case`。正式标定范围为 `606 x 380 cm2`、无 CEGR、`0.1--1.9 A/cm2`、600 s 冷态和 `540--600 s` 尾窗。外部加湿器固定关闭；新鲜空气的唯一水蒸气输入由环境 `20 degC`、`101.325 kPa(abs)`、`50% RH` 导出，`y_H2O=0.01154`。旧 CSV 只用于堆温轨迹插值，未将其中的阴极入口 RH 写入输入或拟合。固定新鲜空气质量流量是无 CEGR 唯一供气边界，OER、氧分压和总入口流量均只作为结果检查。

## 10. 外部 240 kW 阴极气体温度边界更新（2026-08-17）

本节覆盖 P4-A 中“旧 CSV 只用于堆温轨迹”的早期表述，但不改变 `external_case` 边界。`PEMFuelCellSystem_Cathode_cEGR_SelfHumidifying_v01` 的 `Cathode_Air_cEGR_BOP/Oxygen Source/Compressor Volume` 热端口现直接连接官方 `Temperature Source` 块 `Cathode_Gas_Temperature_Boundary`。该块的模型工作区参数为 `focused_cathode_inlet_temperature_C`，用于代表压缩机后至入堆前的合并气体热边界；它不是中冷器效率、热容或热管理模型。

对外部 240 kW case，`routeA_focused_external240kw_case_factory.m` 仅从旧 CSV 插值读取阴极入口气体温度并写入该模型变量；CSV 的阴极入口 RH 继续不参与输入。堆温仍由独立的 `focused_stack_temperature_C` 固定边界写入，二者不可互相替代。无 CEGR 时，新鲜空气水蒸气仍唯一由环境 `20 degC`、`101.325 kPa(abs)`、`50% RH` 导出。

在 `j=0.1 A/cm2`、无 CEGR、600 s 冷态、尾窗 `540--600 s` 的实际回归中，气体热边界设定为 `58.9 degC`、堆温设定为 `61.1 degC`。读回的气体温度链为：压缩机入口混合点 `19.971 degC`、压缩机排出 `58.900 degC`、流阻后 `59.006 degC`、阴极通道 `59.394 degC`、阴极出口 `59.368 degC`。这一结果替代了此前无气体热边界时约 `47.33 degC` 的出口状态。出口温度没有被强制拟合到 CSV 中的 `56 degC`，而是作为固定堆温条件下的模型计算量。

该回归还确认新鲜空气和入堆水蒸气质量流率分别为 `2.98583e-4`、`2.98457e-4 kg/s`，差额约 `0.04%`；故入口 RH 从环境 50% 变为约 8.33% 是气体升温和加压下的相对湿度变化，不是外加湿。模型已通过 `model_check(all)` 的 0 error 检查并由 MATLAB 保存为 `Dirty=off`。此前以约 `47.33 degC` 阴极出口温度计算得到的低负荷 CEGR 数值，只保留为热边界修复前的可运行性记录，不得用于 CEGR 湿化、电性能或能力比较。

**水蒸气口径更新（2026-08-17）：** 后续聚焦模型的混合、回流比、水账本和稳态判据一律以四组分质量流率中的 `m_H2O` 为主。性能结果固定报告新鲜空气、阴极入口和阴极出口的水蒸气质量流率；CEGR 筛选表同步报告这三个量及 `m_cegr`。相对湿度仅作为状态展示量，不作为气体质量、混合或稳态计算输入。冷凝筛选继续由 `m_H2O` 对应的气体组分、温度和绝压导出的水蒸气分压、饱和度和露点完成，而非以 RH 阈值替代物理判据。环境 `20 degC/50% RH` 只在案例边界一次性换算为新鲜空气水蒸气组分。

## 11. 外部 240 kW 模型 A 当前收口状态（2026-08-17）

本节覆盖本文中先前外部 240 kW 的电性能和 CEGR 状态表述。正式模型仍为 `PEMFuelCellSystem_Cathode_cEGR_SelfHumidifying_v01`，固定为 `external_case`；无 CEGR 极化标定已在 `606 x 380 cm2`、`0.1--1.9 A/cm2`、600 s 冷态、`540--600 s` 尾窗内完成。MEA 的当前有效参数是 `stack_io=2e-14 A/cm2`、`stack_alpha=1`、`stack_iL=2.5 A/cm2`、膜厚 `125 um` 和直接写入模型的 2.5 倍导电率表。19 点全量 `Vcell` RMSE 为 `10.172 mV`；11 个留出点 RMSE 为 `8.725 mV`、最大误差为 `15.492 mV`。这些是固定温度、压力、流量和环境边界下的模型有效参数，不宣称为材料本征值。

`stack_io` 和 `stack_alpha` 由 MEA 掩码引用模型工作区变量，正式模型保存值即为上述基线；runner 仍可通过 `SimulationInput` 为后续明确记录的再标定 case 覆盖二者。`j=0.1 A/cm2` 无 CEGR 的 600 s 回归已验证该路径写入和 MEA 掩码读回一致。温度边界源与压缩机容腔的冷态初始条件仍会触发一次优先级松弛警告，但该 case 的 540--600 s 尾窗严格稳态和气相闭合均通过；该警告未被提升为热管理验证结论。

压力结论未改变：出口背压跟踪通过，但单一等效流阻无法解释五个锚点的低流量曲率；现有有效参数组只作为筛选模型设置，不构成电堆真实流道或 BOP 选型标定。热边界和水蒸气质量流率结果契约已在第 10 节冻结。此前的低负荷 CEGR 运行发生在旧的错误气体温度边界下，全部降级为失效的可运行性记录；新热边界下尚未重算 CEGR，因而当前不存在可报告的 CEGR 增湿能力或上限结论。
