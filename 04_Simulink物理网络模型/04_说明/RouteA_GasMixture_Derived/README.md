# Route A Gas Mixture Derived 说明目录

本目录只保存 Route A 说明材料，不保存模型、脚本、MAT 结果或临时输出。为避免“指导文件”和“实施记录”互相覆盖，说明按用途分层。

## 先读顺序

1. [当前指导文件](01_当前指导/README.md)：决定当前模型、边界和实施顺序；
2. [当前实施分卷](02_实施记录/01_当前分卷/)：查看最近一次实施证据和未完成事项；
3. [审计与研究](03_审计与研究/README.md)：查看只读审计和 CEGR 文献映射；
4. [已封闭实施记录](02_实施记录/02_已封闭/)：只用于阶段追溯；
5. [Claude Code 交接材料](04_交接材料/README.md)：仅用于跨客户端交接，不是模型规范。

## 说明文件分类

本项目说明文件按更新方式分为两类：

| 类型 | 目录 | 更新方式 | 详细规则 |
|---|---|---|---|
| **规划设计类** | `01_当前指导/` | 覆盖式更新 | 顶层规划、系统定义、接口规范、资产清单、参数分层。阶段性任务完成后覆盖更新，以最新版本为准。 |
| **实施记录类** | `02_实施记录/` | 增量式更新 | 实际工作、阻塞点、根因、读回证据、验证结果。**每次阶段完成必须追加当前分卷**，记录未经验证的假设不得写为结论。详细触发规则见 `02_实施记录/README.md`。 |

`03_审计与研究/` 和 `04_交接材料/` 不参与以上分类——前者提供只读证据，后者仅用于跨客户端交接。

## 维护规则

- 新的设计决策先更新当前指导文件，再写实施记录；
- 实施记录只记录实际发生的变更、读回、验证和剩余风险，不反向修改指导口径；
- 审计/文献材料提供证据和研究输入，不自动成为模型参数或验收标准；
- 交接词只服务于客户端切换，不作为项目规则的第二入口。
- **阶段性任务完成后必须增量更新实施记录**——记录完成以产物存在和验证通过为准，不以模型结构建成为准。
