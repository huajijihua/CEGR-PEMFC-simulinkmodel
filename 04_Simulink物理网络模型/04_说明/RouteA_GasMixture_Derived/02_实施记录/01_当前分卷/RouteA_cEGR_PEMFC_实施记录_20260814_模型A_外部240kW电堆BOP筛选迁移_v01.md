# Route A cEGR-PEMFC 实施记录：模型 A 外部 240 kW 电堆与 BOP 筛选迁移

日期：2026-08-14
状态：已实现、已结构读回、已执行两组 600 s 正式 case；电化学极化和实际设备热性能未标定
关联当前指导：[两种阀门被动架构聚焦模型改造实施方案](../../01_当前指导/RouteA_cEGR_PEMFC_两种阀门被动架构_聚焦模型改造实施方案_v01.md)

## 1. 目的与输入边界

目标是在不新建模型或 runner 的前提下，将模型 A 的电堆尺度与阴极 BOP 调整到可筛选外部 240 kW 级电堆的量级，并为无 CEGR、空压机后引射方案提供边界数据。外部输入文件为 `00_支撑材料/01_项目系统实验数据/240kw电堆数据.txt`；其电堆几何为 606 片、380 cm²/片，总有效面积 230280 cm²，实测电流密度范围为 0.1--1.9 A/cm²。

该输入在参数层中标记为 `external_case`，其作用范围为 `stack_geometry_airflow_cathode_pressure_drop_and_BOP_screening`。实测范围外的电流密度仅允许筛选外推；不得据此声明平台默认值、硬件额定边界或极化标定完成。

## 2. 实际修改

正式模型为 `01_模型/RouteA_Cathode_cEGR_Focused/PEMFuelCellSystem_Cathode_cEGR_SelfHumidifying_v01.slx`。经 MATLAB MCP 修改、保存并读回后，关键模型工作区参数为：

| 项目 | 值 | 说明 |
|---|---:|---|
| 电堆 | 606 片，380 cm²/片 | 总有效面积 230280 cm² |
| 筛选电流密度上限 | 2.5 A/cm² | 高于 1.9 A/cm² 实测点，仅用于筛选 |
| 阴极额定流量/压降 | 0.27182 kg/s，36.8422 kPa | 外部案例高负荷值 |
| 阴极通道宽度系数 | `sqrt(380/280)` | 使气体端口面积随有效面积几何相似缩放 |
| 中冷器流阻 | 0.40798 kg/s，5 kPa，0.007854 m² | 当前仅有气相流阻 |
| 分离边界流阻 | 0.40798 kg/s，2 kPa，0.004072 m² | 仍是气相边界，不代表真实分离效率 |
| 回流管/阀 | 72 mm，0.001 m² | 通流尺度筛选值，不是阀门选型 |
| 空压机图谱 | 0/50000/80000 rpm | 质量流量-压比筛选图谱，不含效率或功率图 |
| 空压机控制下限 | 3.8 A | 允许 0.1 A/cm² 及以下工况，不再被旧 95 A 下限钳制 |

同时修改既有 `routeA_focused_parameter_defaults.m` 与 `routeA_focused_case_adapter.m`，使正式 runner 的 `SimulationInput` 接收上述外部案例参数。初次诊断发现直接写入模型工作区后，旧的通用 `SimulationInput` 参数链会覆盖这些值，表现为 1875 rpm 的旧压缩机工作点及陈旧 400 片/280 cm² 电堆参数；现已由 case 适配器统一覆盖，预运行读回确认 `stack_num_cells=606`、`stack_area=380`、`stack_iL=2.5` 及 BOP 参数均进入本次 case。

## 4. 无 CEGR 引射器边界支持

两组无 CEGR case 的压缩机出口气相摩尔组分为 `[N2,O2,H2,H2O]=[0.7785,0.2100,0,0.0115]`，质量组分为 `[0.7589,0.2339,0,0.0072]`。给引射器计算人员的完整测点、流量、绝压、温度和限制见：[RouteA_Focused_NoCEGR_EjectorBoundary_20260814.md](../../../../../03_结果/RouteA_Cathode_cEGR_Focused/RouteA_Focused_NoCEGR_EjectorBoundary_20260814.md)。

可用范围是系统级入口边界筛选：气相组分、总质量流量和绝压。压缩机在此模型中是质量流量源加筛选转速图谱，中冷器只是气相流阻；文件中的温度只描述当前模型内部状态，不能代替真实压缩机出口热状态、中冷器换热性能或引射器热设计边界。

## 5. 剩余风险与下一步

1. 用外部 0.1--1.9 A/cm² 极化数据校准 MEA，独立报告电压误差后才讨论电堆功率。
2. 与数据提供方确认湿/干压力和流量测点，以决定是否调整阴极通道、背压或外围管路压降。
3. 引射器模型返回压比和混合损失后，将其作为受控支路接入独立新拓扑；不在本次无 CEGR 基线中假设其回流能力。
4. 若需要温度作为设计边界，先补充压缩机效率/功率和中冷器热侧模型或来自台架的实测热状态。

## 6. 无 CEGR 交接表最终复核（2026-08-14）

前述结果表中的早期文件名没有显式区分 `focused_legacy` 与模型 A。最终交接已使用 `modelId="self_humidifying"` 重跑，并在 MAT 结果中核对：
