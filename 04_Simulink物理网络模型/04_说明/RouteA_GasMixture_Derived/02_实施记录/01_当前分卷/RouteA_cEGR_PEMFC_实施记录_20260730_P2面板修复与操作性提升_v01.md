## 1. 本轮范围

本轮按 P2 面板修复口径实施 UI 和交互层调整，目标是让集中窗口更适合继续扩展，并保持“UI -> `simCase` -> `routeA_validate_case` -> `SimulationInput` -> 当前模型 -> 窗口反馈”主链不变。

本轮没有运行 Simulink 工况，没有修改或保存正式 `.slx`，没有新增历史仿真结果、结果图片或模型副本。

## 2. 实际完成项

### 2.1 窗口和配置层

- 隐藏左侧系统域导航，布局改为“系统配置 + 结果与诊断”两栏；内部导航对象仅保留兼容性引用，不再占用可见空间。
- 配置层固定为基础、 高级、系统模型参数、帮助四个入口。
- 增加“加湿温度”输入语义，并在基础/高级输入标签中补充压力、流量、RH、组分、控制器和求解器单位。
- 高级区按“电边界与电压控制、阴极进气/组分/湿度、cEGR、热边界与数值求解、阳极扩展输入”分组。
- 增加帮助层，解释 Current/Power/Voltage 控制原理、空气模式互斥、RH 与温度语义、cEGR 主入口、结果清空范围和输入生效链。
- 同步面板内状态标识和当前指导文件中的阶段顺延：P2 为面板修复，cEGR 研究为 P3，阳极/冷却为 P4，设备参数为 P5，结果迁移为 P6。

### 2.2 结果图像

- 结果页的“时序”入口改名为“结果图像”。
- 增加“电流-时间、功率-时间、电压-时间”三个切换按钮。
- 成功结果按 `caseId` 保存在当前 MATLAB 会话的图像历史中；重复 `caseId` 使用序号区分。
- `清空结果` 只清结果表，保留图像历史；新增 `清空图像` 只清曲线历史，不修改输入和模型。
- 失败结果不再清除既有成功曲线。

### 2.3 本轮语义与排版修复

- 基础页 RH 标签改为“加湿器出口 RH (-)”，高级页沿用同一语义；RH 表示加湿器出口/阴极入口相对湿度，温度参考不是新鲜空气源温度。
- 基础页“加湿温度 (C)”与“堆温/加湿温度 (C)”保持同步，均写入同一个 `controls.thermal.stackTemperatureSet_C`；模型当前加湿器 `TIn` 由现有 `T_stack` 路径提供。高级页的“源温度 (C)”单独保留为新鲜空气入口边界。
- 空气模式 3 的显示名称改为“空压机命令”，字段固定标注 `[0,1]`；其语义为归一化空压机执行命令，绕过目标流量/OER换算和流量 PI，但仍经过空压机图谱，不是直接给电堆气体。
- 高级页阴极控制和阳极扩展输入改为统一左右两列坐标，目标流量与空压机命令分行，源压力/源温度和阳极长标签不再共用窄列。
