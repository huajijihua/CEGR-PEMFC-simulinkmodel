# RouteA cEGR-PEMFC 工程化建模规格 v01

状态：Phase 1 参数匹配与接口契约审计已通过；后续按专题小提交升级。
当前主模型：`PEMFuelCellSystem_GasMixture_cEGR_RouteA_v01.slx`。
当前全工况入口：`run_routeA_fullcase_study.m`；匹配审计入口：`run_routeA_phase1_matching_audit.m`。

## 1. 定义

Route A 是一个 50 kW 级、官方 Gas Mixture PEMFC 案例派生的模块化系统集成平台。它以单一 Simulink/Simscape 物理网络为核心，通过参数层和编译期 cEGR 变体覆盖无 cEGR 与有 cEGR 工况，并为后续台架、车载和具体产品配置保留明确的复用边界。

本模型用于研究电堆与供氧、供氢、热管理、受控负载接口之间的物理耦合、参数匹配和控制约束。它不是当前阶段的产品数字孪生、三维机械装配模型或完整高压电气系统模型。

## 2. 工程化目标

1. 基于可追溯的物理网络和参数来源，计算功率、物质、压力、温度、湿度与热负荷的系统级响应。
2. 由电堆功率和反应需求推导 BOP 的流量、压力、热管理和控制能力要求，而不是孤立调整模块参数。
3. 维持一套模型、一个 `platform_default` 参数源和一个全工况研究入口；产品或台架数据只能经显式 profile 或 `external_case` 接入。
4. 允许以不破坏系统接口的方式，将 L2 设备接口逐步替换为经过参数匹配或标定的部件模型。

## 3. 系统边界与架构

| 工程域 | 当前模型责任边界 | 当前保真度定位 |
|---|---|---|
| 电堆核心 | MEA、阴阳极气道、出口容腔、堆热和电气端口 | 官方物理网络内核 |
| 供氧与 cEGR | 空气源、压缩机/地图、入口混合、中冷接口、阴极加湿、回流阀/管、排气、背压和阴极水管理接口 | 官方物理网络加 L2 设备接口 |
| 供氢 | 储氢、减压、阳极加湿、回流、排氮与阳极水管理接口 | 官方主结构加 L2 回流/分离接口 |
| 热管理 | 冷却通道、泵、散热器、环境换热和控制接口 | 官方热液网络，待做能力匹配与控制闭合 |
| 电气 | 受控负载、电流/电压/功率测量 | 系统边界接口；不在当前阶段建立 DCDC、母线和辅电架构 |
| 控制与观测 | 空气、cEGR、背压、湿度、冷却接口以及 KPI | 研究级控制接口；不是完整产品控制软件 |

cEGR 是供氧/阴极排气水管理域的一条可切换物理支路，不是并行的第五套产品 BOP。无 cEGR 通过 `cEGR_Mode_Selector` 的官方无限流阻隔离实现；有 cEGR 保留排气、水分离、阀、回流管和入口混合链。

## 4. 接口原则

| 类别 | 当前或后续接口 |
|---|---|
| 控制输入 `u` | 功率请求、空气模式与 OER/质量流量目标、cEGR 模式与目标比值、阴极出口压力目标、加湿器与冷却控制量 |
| 外界输入 `w` | 环境压力/温度/RH、氢源状态和组分、初始状态、后续显式配置的台架或产品边界 |
| 控制测量 `y` | 电流、电压、功率、压缩机入口流量、cEGR 流量/比值、阴极出口压力、RH、温度、冷却相关测量 |
| 审计真值 `z` | 实际入堆氧质量流和 `lambda_ca_in`、内部组分、热量、分离水 KPI、执行器饱和与物理节点状态 |

控制命令不能代替物理验收。特别是 OER 命令不能代替实际氧供给，cEGR 评价必须以混合气组分、实际氧计量比和压力链为准。

`routeA_cegr_enabled` 是仅在独立仿真前 `update diagram` 生效的编译期变体，禁止在单次连续仿真中切换。无 cEGR case 同时要求该变体关闭且目标回流比为零；有 cEGR case 的阀面积、阀前后压力和实际回流比均只作为 `z` 审计量，不反馈修改现有控制律。连续 Simscape 物理量按 variable-step 处理。

Phase 1 审计只在 base workspace 生成 `routeA_phase1_audit`。其包含反应/冷却账本、参数注册表、接口契约、被动 cEGR 诊断和缺口表；不导出 CSV、图片、模型副本或缓存。若当前 base workspace 已有同一模型、同一 9 工况矩阵定义的完整结果，审计入口复用该结果，只补充两条被动 cEGR 诊断。

## 5. 保真度与参数规则

1. 官方 `FuelCell_lib` 和官方案例直接覆盖的物理内容优先复用。
2. 中冷器、水分离器、压缩机机械动态、氢循环装置、加湿器水热传递、节温与 PTC 等未充分实现内容必须标明为 L2 接口、待升级设备或待标定模块。
3. 每项可调参数后续必须归入机理参数、设备能力参数、控制参数或数值参数，并记录单位、来源、适用范围和验证状态。
4. 不以数值收敛替代工程真实性；也不因暂缺产品数据而提前建立无法验证的高保真动态。

## 6. 当前阶段判定

Route A 已完成官方派生物理网络、cEGR/no-cEGR 单模型变体、50 kW 平台参数基线、九个稳态全工况功能性验证，以及 Phase 1 的反应/冷却量级账本与接口契约审计。无 cEGR 回流严格为零；0.10/0.30 cEGR 的回流跟踪、实际入堆氧计量比和尾段功率稳定性均通过现行门槛。名义负载下的被动阀诊断确认两种 cEGR 目标均具有正向阀前后压差，且阀面积未触及上限。

当前可作出的结论仅限系统级工程量级闭合和控制/物理网络行为。压缩机仍是流量源/地图接口，不代表效率、轴功率或喘振裕度已经验证；阳极 lambda、purge、循环器能力，水分离效率，冷却泵的流量能力/功率，以及散热器 UA/风量仍是明确的 L2 待证能力。

当前尚未完成：真实空压机效率/轴系与喘振边界、真实中冷/加湿/水分离能力、氢循环器或引射器、阳极 purge/lambda 闭环、完整热管理控制、DCDC/辅电架构、产品级标定和独立实验验证。
