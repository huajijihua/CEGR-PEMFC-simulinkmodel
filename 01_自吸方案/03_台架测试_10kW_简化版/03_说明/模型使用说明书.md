3. 在 Command Window 输入：

## 1. 模型定位

本模型是 10 kW 短堆台架稳态 EGR 回放与工况研究模型。它以整理后的台架稳态点为输入，计算阴极混合气组成、膜水状态、热平衡、电压、气体/水守恒诊断和 EGR 回流影响。

当前模型不是整车系统模型，也不是完整 BOP 动态模型。它默认使用台架已测得的入口流量、入口压力、出口背压、阳极边界和冷却边界，重点检查电堆核心、EGR 回流、分离器和入口混合链路。

## 7. 顶层模块与气路链路

模型顶层包含 7 个 MATLAB Function 核心模块：

```text
BenchAirSupplySimplified
EGRMixerSimplified
BenchInletConditioner
PEMFCStackCore
EGRSplitterSimplified
WaterSeparatorSimplified
SystemSummarySimplified
```

主链路：

```text
CaseBoundaryParam
  -> BenchAirSupplySimplified
  -> EGRMixerSimplified
  -> BenchInletConditioner
  -> PEMFCStackCore
  -> EGRSplitterSimplified
  -> WaterSeparatorSimplified
  -> EGRFeedbackDelay
  -> EGRMixerSimplified
```

含义：

- `BenchAirSupplySimplified`：把台架供气 p/T/RH 换算后的 O2/N2/H2O 质量分数整理成新鲜气向量。
- `EGRMixerSimplified`：把新鲜气和延迟回来的 EGR 气体混合，并保证入堆总质量流量等于工况目标。
- `BenchInletConditioner`：用实测入堆温度和压力覆盖混合气边界，并处理入口水蒸气饱和限制。
- `PEMFCStackCore`：计算电压、热、膜水、气体库存、反应消耗、出口状态和核心诊断。
- `EGRSplitterSimplified`：按 EGR 比例把电堆出口分成回流支路和台架外排支路。
- `WaterSeparatorSimplified`：按分离器温压对回流气体做冷凝排水和气相输出。
- `SystemSummarySimplified`：汇总关键电压、气体、水、热、流量和风险诊断。

模型不使用“直接 EGR 电压惩罚项”。EGR 对电压的影响必须通过氧浓度、氧分压、压力闭合、水汽/膜水和热状态体现。

## 10. 自定义进气研究

正式入口：

```matlab
results = run_testbench_10kw_simplified_custom_inlet_study(120);
```

研究口径：

- 只使用 13 个 `initial_noegr_steady_xlsx` 主 no-EGR 点作为电流锚点。
- 新鲜空气统一按 `25 C / 1 atm(abs) / 50% RH` 计算组分。
- 每个电流点先解析历史 `lambdaO2_initial`，再在新空气组分下反算 no-EGR 总入堆流量。
- 开 EGR 后总入堆质量流量保持不变。
- 入堆压力和入堆温度沿用台架点。
- 分离器出口压力沿用该点 `stack_out_p_kPa`。
- 分离器出口温度用 `stack_out_T` 迭代回写，最多 3 次，收敛门槛 `0.5 C`。
- `lambda_O2_actual < 1.2` 标记为缺气风险工况。

输出位置：

```text
04_验证结果/custom_inlet_study_v01/
```

关键文件：

```text
custom_inlet_case_definition.csv
custom_inlet_egr_scan.csv
custom_inlet_summary.md
humidified_reference_scan.csv
humidified_reference_summary.md
```

这些结果只服务自定义工况研究，不写回活动拟合输入表。

## 12. 标定脚本使用边界

电压标定：

```matlab
calibrate_testbench_10kw_simplified_egr
```

压力标定：

```matlab
calibrate_testbench_10kw_simplified_pressure
```

温度标定：

```matlab
calibrate_testbench_10kw_simplified_temperature
```

使用原则：

1. 先确认边界输入、流量、压力顺序和守恒残差正确。
2. 温度残差明显时先查热参数和冷却曲线，不用电压参数补偿。
3. 压力/流量链路异常时先查 `V_ca_m3`、`V_an_m3`、`K_ca_out_kg_s_kPa`、`K_an_out_kg_s_kPa`。
4. 湿度、膜水和欧姆损失异常时再查 `tau_mem_s` 与膜水模型。
5. 不把 EGR 绝对电压误差单独作为“已完成机理标定”的证据。

## 13. 合格性检查清单

运行或修改后至少检查：

```text
数据回放：电流、入堆流量、入口压力、出口压力、EGR 比例和实验电压一致。
边界输入：mIn_kg_s 不为 0，lambdaO2 不被入口压力或组分错误压成 0。
气体守恒：maxGasRes_kg_s 在数值误差量级。
水链路：RH、冷凝、膜水没有明显越界或非物理突跳。
压力链路：内部阴极/阳极压力与进出口边界顺序一致。
EGR 趋势：EGR 增大时入口氧摩尔分数下降。
电压诊断：etaAct、etaOhm、etaCon 的方向与工况变化一致。
缺气风险：lambdaO2 < 1.2 的点单独标记，不混入正常电压趋势结论。
```

电压拟合只能排在边界、守恒、压力、湿度和热链路检查之后。

## 14. 常见问题

### 14.1 `caseIndex out of range`

检查 `dataMode`。例如 `initial_noegr` 只有 13 个点，`egr` 当前只有 12 个正 EGR 点，`all` 才是 29 个点。

### 14.2 仿真找不到模型

确认已从 `02_脚本` 目录运行，或手动加入模型目录：

```matlab
addpath('E:\agentwork_pemfc_cEGR_0519\01_自吸方案\03_台架测试_10kW_简化版\01_模型')
```

### 14.3 入口流量为 0 或 `lambdaO2` 异常

优先检查：

```text
combined_noegr_cegr_fit_points.csv 中 stack_in_flow_meter_SLPM 是否缺失或非正
bench_supply_p_actual_kPa / bench_supply_T_C / bench_supply_RH_pct 是否可换算
CaseBoundaryParam_simplified(4) 是否为正
fresh_node 和 mixer_node 的前四项是否为有效质量分数/质量流量
```

### 14.4 电压误差变小但 EGR 趋势不合理

不能只看 RMSE。必须同时看 `xO2_ca_in`、`pO2_ca_in_kPa`、`lambdaO2`、`etaAct_V`、`etaOhm_V` 和 EGR 相对 no-EGR 电压变化。当前模型要求保留低氧浓度下活化损失增大的方向。

### 14.5 高 EGR 工况仿真电压降小于实验

这是当前冻结基线的已知限制之一。当前结果可用于趋势研究，但不能表述为 EGR 机理已经被专项实验充分定量验证。

### 14.6 温度结果不合理

先检查冷却入口温度、冷却流量和 `simplified_thermal_params.csv`。当前 `T_stack` 按阴极入口/出口平均温度解释，阴极出口温度用 `T_ca_out = 2*T_stack - T_ca_in` 估算。

- 不新建无意义的 `.slx` 副本；结构修改前应说明目的并保留一条清晰主线。
- 若要提交版本，先区分模型、脚本、输入参数和结果文件，避免把旧缓存或临时图片混入提交。

## 16. 结论使用边界

当前模型可以支持：

```text
统一台架工况回放
no-EGR 与 CEGR 边界一致性检查
入口组分、EGR 比例、氧计量比和缺气风险趋势分析
温度、压力、膜水和电压链路的半定量诊断
自定义进气条件下的趋势扫描
```

当前模型不应直接用于：

```text
替代整车空压机/引射器/阀件动态模型
给出未经台架验证的高 EGR 定量性能承诺
用电压 RMSE 单独证明 EGR 机理已充分标定
把低流量冷却等效换热参数外推为真实冷却系统性能
把某次标定参数解释为唯一物理识别结果
```
