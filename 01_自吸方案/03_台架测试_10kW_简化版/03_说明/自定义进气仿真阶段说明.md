# 自定义进气仿真阶段说明

## 目的

当前简化台架建模、边界整理、模块耦合、方程表达式和参数拟合已完成到可研究阶段。本阶段不再继续改动电堆、电压、热、压力和膜水参数，而是切换到自定义进气边界研究：

- 不再使用历史台架供气组分。
- 新鲜空气统一按 `25 C / 1 atm(abs) / 50% RH` 计算组分。
- 入堆压力、入堆温度继续沿用各台架点。
- 无 EGR 总入堆流量按各初始 no-EGR 点的 `lambdaO2_initial` 重新反算。
- 开 EGR 后总入堆质量流量保持不变，只扫描 EGR 比例。

这里的“无加湿”指无外部加湿器，只保留环境空气自带的 `50% RH` 水汽，不是零湿度干空气。

## 当前冻结基线

本阶段默认冻结以下内容，不重新标定：

- `PEMFCStackCore` 中的电压、热、膜水和气体库存方程。
- `simplified_noegr_stack_params.csv` 中的电压相关参数。
- `simplified_thermal_params.csv` 中的冷却曲线。
- `simplified_pressure_params.csv` 中的库存体积和出口等效导纳。

当前电压冻结验收以 `04_验证结果/voltage_fit_v01/voltage_fit_metrics.csv` 为准：

- `no-EGR RMSE = 4.32 mV`
- `no-EGR max abs = 7.88 mV`
- `EGR validation RMSE = 10.63 mV`
- `EGR validation max abs = 18.72 mV`

如果 `fit_overview_v01/current_fit_summary.csv` 的电压指标和上述文件不一致，以 `voltage_fit_metrics.csv` 为准。`current_fit_summary.csv` 只是展示汇总，必须用当前残差 CSV 重生后才有效。

## 仿真入口

正式入口：

- `02_脚本/run_testbench_10kw_simplified_custom_inlet_study.m`
- `02_脚本/run_testbench_10kw_simplified_humidified_reference_study.m`

初始化脚本：

- `02_脚本/init_testbench_10kw_simplified_egr.m`

初始化脚本现在支持可选第四参数 `override`，但只允许覆盖下列边界字段：

- `bench_supply_gas_p_kPa`
- `bench_supply_gas_T_C`
- `bench_supply_gas_RH`
- `stack_in_flow_kg_s`
- `stack_in_flow_SLPM`
- `egr_fraction_cmd`
- `separator_T_C`
- `separator_p_kPa`

这类 override 只服务工况研究，不允许借此改动结构参数或标定参数。

## 研究口径

电流锚点：

- 只使用 `initial_noegr_steady_xlsx` 的 13 个主 no-EGR 点。

EGR 分段扫描：

- 低负载 `j = 0.1/0.2/0.3 A/cm2`：`EGR = 0:0.05:0.70`
- 中负载 `j = 0.4/0.6/0.7/0.9/1.1 A/cm2`：`EGR = 0:0.05:0.40`
- 高负载 `j = 1.3/1.5/1.7/1.8/1.9 A/cm2`：`EGR = 0:0.05:0.30`

每个扫描点的边界约定：

- `boundary(2:3)`：继续用该点现有台架入堆压力/温度。
- `boundary(4)`：固定为该点重算后的总入堆质量流量。
- `boundary(5:7)`：统一使用环境空气组分。
- `boundary(11)`：按扫描值给 EGR 比例。
- `boundary(9:10)`：分离器出口压力用该点 `stack_out_p_kPa`，分离器出口温度用 `stack_out_T` 迭代回写，最多 3 次，收敛门槛 `0.5 C`。

结果统一写到：

- `04_验证结果/custom_inlet_study_v01/`

关键输出文件：

- `custom_inlet_case_definition.csv`
- `custom_inlet_egr_scan.csv`
- `custom_inlet_summary.md`
- `humidified_reference_scan.csv`
- `humidified_reference_summary.md`
- `plot_testbench_10kw_simplified_custom_inlet_study.m` 打开五张 MATLAB 图窗：低/中/高负载电压图各一张，另有 `lambdaO2` 和入口干基含湿量图。电压趋势只显示非缺气、气体守恒合格点；缺气/残差异常点只计数标注，不直接进入电压坐标轴。

这些输出只服务本阶段研究，不写回 `combined_noegr_cegr_fit_points.csv`。

其中“加压加湿 no-EGR 参考线”采用以下口径：

- 只取 13 个 `initial_noegr` 主点，不跟随 EGR 再做二次扫描。
- 直接回放各点原生台架边界，代表正常加压加湿供气下的 no-EGR 稳态结果。
- 参考线口径用 `00_支撑材料/实验数据-设备说明书/电堆信息及推荐测试工况.xlsx` 逐点核对，不再把供气退回到环境 `25 C / 1 atm` 再施加 RH。

若要解释“湿度降低为何在某些负载段不再明显拉低电压”，使用 `02_脚本/diagnose_testbench_10kw_simplified_humidity_sensitivity.m` 做定点诊断。该脚本不改模型参数，只对比 `dry` 与加压加湿 no-EGR 参考线下的膜含水、冷凝、跨膜水通量、氧分压和欧姆损失。

当前活动机理下，膜面阴极蒸汽活度不再直接取完全混合 bulk，而采用“双库存 + 小权重入口修正”口径：bulk 水库存继续负责总质量守恒，膜面活度则使用不含本步产水直接顶湿的 `activity reservoir`，并对阴极膜面蒸汽分压采用 `pV_mem,ca = 0.02*pV_in + 0.98*pV_bulk` 的通道平均近似。

## 验收重点

- 每个锚点都能解析历史 `lambdaO2_initial`。
- 用新环境反算的 no-EGR 流量回放后，`lambdaO2` 相对目标误差满足 `±1%` 或 `±0.02` 的较宽门槛。
- 同一电流点下，`xO2_in` 必须随 EGR 增大而下降。
- `lambda_O2_actual < 1.2` 直接记为缺气风险工况，应在摘要和扫描表中单独监测。
- 守恒残差不能明显恶化；如果异常，应优先回到边界和物理链路解释，不回头用电压参数补偿。
- 本阶段结论只用于趋势判断，不包装成已经被 EGR 专项实验充分验证的定量结论。
